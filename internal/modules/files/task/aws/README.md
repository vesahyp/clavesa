# task (aws)

One task of a Databricks bundle job run on clavesa (ADR-031). The task's
own code writes its tables, so the module creates nothing: the pipeline's
orchestration (Step Functions, the runner) runs every task of the job in
one runner, from the job's `bundle-job.json`. The module block exists so
the pipeline graph, the UI and the run history see one node per task.

Generated by `clavesa bundle deploy` / `clavesa bundle run`; never edited
by hand. Change the task in the bundle's `databricks.yml`.
