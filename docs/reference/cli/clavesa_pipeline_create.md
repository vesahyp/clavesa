# clavesa pipeline create

Create a new pipeline

## Usage

```
clavesa pipeline create <name> [flags]
```

## Flags

```
      --schema string   ADR-016 schema identifier (default: sanitized pipeline name)
```

## Global flags

```
      --workspace string   workspace root directory (default: current directory)
```
