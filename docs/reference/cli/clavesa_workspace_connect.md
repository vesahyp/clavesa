# clavesa workspace connect

Connect the workspace to an outside catalog

## Usage

```
clavesa workspace connect
```

## Global flags

```
      --keep-metastore     leave the workspace's shared metastore container running after this command exits (env CLAVESA_KEEP_METASTORE=1)
      --workspace string   workspace root directory (default: current directory)
```

## Subcommands

- [clavesa workspace connect databricks](clavesa_workspace_connect_databricks.md) — Write this workspace's tables into a Databricks Unity Catalog
