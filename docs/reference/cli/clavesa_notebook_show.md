# clavesa notebook show

Print the notebook (cell sources, no outputs)

## Usage

```
clavesa notebook show <name> [flags]
```

## Flags

```
      --json   Emit nbformat JSON (full .ipynb)
```

## Global flags

```
      --workspace string   workspace root directory (default: current directory)
```
