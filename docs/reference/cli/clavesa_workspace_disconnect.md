# clavesa workspace disconnect

Remove a connection to an outside catalog

## Usage

```
clavesa workspace disconnect
```

## Global flags

```
      --keep-metastore     leave the workspace's shared metastore container running after this command exits (env CLAVESA_KEEP_METASTORE=1)
      --workspace string   workspace root directory (default: current directory)
```

- [clavesa workspace disconnect databricks](clavesa_workspace_disconnect_databricks.md) — Remove the Databricks connection from clavesa.json
