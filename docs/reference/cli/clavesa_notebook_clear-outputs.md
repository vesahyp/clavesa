# clavesa notebook clear-outputs

Clear all cell outputs (matches `jupyter nbconvert --clear-output`)

## Usage

```
clavesa notebook clear-outputs <name>
```

## Global flags

```
      --keep-metastore     leave the workspace's shared metastore container running after this command exits (env CLAVESA_KEEP_METASTORE=1)
      --workspace string   workspace root directory (default: current directory)
```
