# clavesa notebook session

Manage notebook REPL sessions

## Usage

```
clavesa notebook session
```

## Global flags

```
      --workspace string   workspace root directory (default: current directory)
```

## Subcommands

- [clavesa notebook session stop](clavesa_notebook_session_stop.md) — Stop the REPL subprocess for a notebook (loses Python globals)
